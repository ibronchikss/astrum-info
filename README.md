# ASTRUM — сайт ванильного Minecraft-сервера

Статичная копия главной страницы сайта https://site-29913.host-ai.pro/
IP сервера: **astrums.pro**

Сайт собран из сохранённой страницы: HTML и CSS — оригинальные, без баннера
конструктора и служебных скриптов Next.js. Сборки и исходников конструктора здесь нет.

## Структура

```
index.html               — главная страница
assets/css/style.css     — оформление (оригинальный CSS)
assets/js/main.js        — мобильное меню, копирование IP, индикатор онлайна
assets/images/hero-bg.png     — фон первого экрана
assets/images/astrum-logo.png — логотип (он же иконка вкладки)
art/                     — сюда нужно положить star-world-map.svg (см. ниже)
```

## Как открыть

Локально: откройте `index.html` в браузере.

На GitHub Pages: **Settings → Pages → Build and deployment → Source: Deploy from a branch →
Branch: `main` / `/ (root)` → Save.** Через минуту-две сайт появится по адресу
`https://<ваш-ник>.github.io/<название-репозитория>/`.

## Чего пока не хватает

1. **`art/star-world-map.svg`** — фон блока «Карта звёздного мира». Пока файла нет, блок
   показывается тёмным без картинки. Скачать: https://site-29913.host-ai.pro/art/star-world-map.svg
2. **Остальные страницы** — «Магазин», «Правила», «Вики», «Навигация», «Прочее». Ссылки на них в
   меню пока ведут на живой сайт host-ai.pro. Когда страницы будут добавлены в репозиторий
   (`shop.html`, `rules.html` и т.д.), замените эти ссылки на локальные.
3. **Шрифт Manrope** подключается с Google Fonts (`@import` в начале `style.css`), нужен интернет.

## Важно про `assets/js/main.js`

Оригинальный JavaScript получить не удалось, поэтому скрипт написан заново по разметке:

- кнопка меню на телефоне открывает и закрывает навигацию;
- клик по блоку «IP сервера» копирует `astrums.pro`;
- кнопка «Начать играть» прокручивает страницу к блоку «Первые шаги»;
- индикатор онлайна запрашивает `https://api.mcsrvstat.us/3/astrums.pro` и обновляется раз в 5 минут.
  Это предположение: какой источник данных использовал оригинал, неизвестно.

Если у вас есть исходный проект сайта, лучше хранить в репозитории его.
